# Einmalige Einrichtung

Damit du deine Website später selbst bearbeiten kannst, braucht es einmal
diese fünf Schritte. Danach nie wieder.

Rechne mit etwa 10 Minuten.

---

## Was ist der „Bearbeitungs-Link"?

Das ist die Adresse deiner Website mit **`/admin/`** am Ende.

Also zum Beispiel:

| | |
|---|---|
| Deine Website | `https://lino-gautschi.ch` |
| Bearbeitungs-Link | `https://lino-gautschi.ch/admin/` |

Dort öffnet sich kein normaler Website-Besuch, sondern eine Eingabemaske, in
der du Texte, Resultate, Sponsoren und Bilder änderst. Den genauen Link
bekommst du mitgeteilt.

Normale Besucher deiner Website sehen davon nichts.

---

## Schritt 1 – Konto bei GitHub erstellen

GitHub ist der Ort, an dem deine Website gespeichert liegt. Du brauchst dort
ein Konto, damit nur du etwas ändern kannst. Sonst musst du dich mit GitHub
nie beschäftigen.

1. **github.com/signup** öffnen
2. E-Mail-Adresse eingeben
3. Passwort ausdenken
4. Benutzernamen ausdenken, z.B. `lino-gautschi`
   → Der ist frei wählbar und erscheint **nicht** auf deiner Website.
5. Die Frage nach Werbe-E-Mails kannst du mit `n` beantworten
6. Eine kleine Rätselaufgabe lösen (Sicherheitsprüfung)
7. Du bekommst einen Code per E-Mail → eingeben
8. Falls nach Interessen oder einem Bezahlplan gefragt wird:
   überspringen bzw. **„Free"** wählen

> **Die Seite ist auf Englisch.** Das ist normal und kein Fehler.

---

## Schritt 2 – Benutzernamen weitergeben

Schick deinen GitHub-Benutzernamen weiter (den aus Schritt 1, Punkt 4).

Ohne diesen Schritt kannst du dich zwar anmelden, aber nichts speichern.

---

## Schritt 3 – Einladung annehmen

1. Du bekommst eine E-Mail von GitHub. Betreff ungefähr:
   *„… invited you to collaborate"*
2. **Falls keine E-Mail kommt: im Spam-Ordner nachsehen.**
3. In der E-Mail auf den grünen Knopf klicken
4. Auf der Seite, die sich öffnet, auf **„Accept invitation"** klicken

---

## Schritt 4 – Zum ersten Mal anmelden

1. Den **Bearbeitungs-Link** öffnen (Website-Adresse + `/admin/`)
2. Auf **„Mit GitHub anmelden"** klicken
   → Die beiden anderen Möglichkeiten auf dem Bildschirm brauchst du nicht.
3. GitHub fragt, ob die Website auf dein Konto zugreifen darf.
   Auf den grünen Knopf **„Authorize"** klicken.
4. Fertig – du siehst jetzt die Bereiche *Startseite*, *Resultate*,
   *Sponsoren* und *Galerie*

Diese Erlaubnis musst du nur einmal geben. Danach bist du in der Regel
angemeldet und kommst direkt hinein.

---

## Schritt 5 – Link griffbereit ablegen

Damit du den Link nicht jedes Mal suchen musst:

**iPhone (Safari)**
Link öffnen → Teilen-Symbol unten → *Zum Home-Bildschirm*

**Android (Chrome)**
Link öffnen → die drei Punkte oben rechts → *Zum Startbildschirm hinzufügen*

**Computer**
Link öffnen → `Strg` + `D` (Windows) bzw. `Cmd` + `D` (Mac)

Auf dem Handy hast du danach ein Symbol wie bei einer App.

---

## Geschafft

Ab jetzt kannst du Inhalte ändern: Link öffnen, Bereich wählen, ändern,
auf *Speichern* klicken. Nach rund einer Minute ist es auf der Website zu
sehen.

Wie das genau geht, wird dir direkt gezeigt.
